### 1.2 研究意义

【写2段】

- **理论意义**：针对网络不稳定环境下的电力数据采集可靠性问题，研究本地缓存与重传机制的结合方案，补充现有DTU网关研究的空白。

#### 3.4.2 总体方案

【本地缓存 + 重传机制结合】

```
采集数据
   │
   ├─→ [立即MQTT发布] ──→ 成功 → 标记 uploaded=1
   │                    └─→ 失败 → 存入SQLite，标记 uploaded=0
   │
   └─→ 定时任务（每60秒）检查 uploaded=0 的记录
                            │
                            ├─→ 网络恢复 → 批量重传 → 标记 uploaded=1
                            └─→ 网络仍断开 → 等待下次轮询
```
