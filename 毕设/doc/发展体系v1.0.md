个人发展与考研路线体系（Release v1.0）
定位声明：
本体系用于 21–25 岁阶段的长期发展决策，目标是在不孤注一掷的前提下，实现高上限、可修正、可执行的成长路径。它是工具，不是信仰；是操作系统，不是身份标签。

一、核心总原则（不可违背）
1. 目标刚性，路径弹性
● 长期目标：不因短期反馈轻易改变（如：清华/顶级平台/长期能力跃迁）
● 中短期路径：允许调整、替换、重构
● 判据：连续 2 个反馈周期失败 + 明确可归因到方法或结构
2. 以现实反馈为最高裁判
● 不以情绪、感觉、自尊作判断依据
● 只承认：结果、进度、可验证产出
3. 不押单点事件
● 不把人生押在一次考试、一次面试、一次选择
● 每一步都必须具备可复用价值
4. 框架服务行动，而不是替代行动
● 框架存在的唯一意义：
让你在做事时更稳，而不是让你觉得自己更清醒

二、你当前的真实阶段定位
阶段定义：
认知明显提前，但现实成果仍在追赶；
已脱离普通同龄人状态，但尚未进入“结果定义期”。
● 不是新手
● 不是高位成熟者
● 属于：结构化成长早期阶段
此阶段的正确策略：
● 少人生总结
● 多现实交付

三、总体路线结构（主干不变）
阶段 0（当前 – 6 个月）｜现实落地期
核心任务：站稳现实结构
● 找到并稳住一份可成长型工作（优先 C++ 后端 / 系统 / 工程向）
● 建立稳定作息、身体与输出节律
关键指标：
● 是否有持续输出（项目 / 技术积累）
● 是否获得真实反馈（面试 / 工作评价）

阶段 1（6 – 18 个月）｜能力复利期
核心任务：让每一份努力可叠加
1. 工程能力
  ○ C++ / 系统 / 后端方向深度积累
  ○ 项目必须满足：可讲清、可展示、可复用
2. 算法与理论
  ○ CSP 系列（兼顾就业与考研）
  ○ 算法训练以“模型理解”为主，而非刷题数量
3. 学习体系
  ○ 建立个人知识结构，而不是课程堆砌

阶段 2（18 – 36 个月）｜考研与跃迁期
核心任务：将积累转化为平台跃迁
● 目标：清华（含深圳研究生院）
● 准备重点：
  ○ 826 专业课（长期、分阶段）
  ○ 复试能力：项目、科研潜力、表达
原则：
● 考研是一次“放大器”，不是唯一出路
● 即使失败，能力与履历仍可继续滚动

四、有效反馈的三分类（用于判断是否调整）
A 类｜健康延迟反馈（不调整）
● 慢，但方向正确
● 积累型、复利型进展
B 类｜方法错配反馈（修正路径）
● 忙但不涨
● 转化率低
C 类｜结构性失败反馈（重构路径）
● 长期投入产出比极低
● 成果不可复用
注意：情绪波动 ≠ 坏反馈

五、允许比较，但必须用对地方
❌ 禁止比较
● 认知高度
● 潜在上限
● 人生叙事完整度
✅ 唯一允许的三项比较指标
1. 输出密度：30 天内是否有可验证成果
2. 修正速度：犯错后多久能调整
3. 稳定性：是否越来越不依赖情绪

六、常见高风险误区（重点警告）
1. 过度推演，侵蚀执行
2. 把阶段性清醒当成终态成熟
3. 频繁调整路线，打断长期复利
4. 把框架本身当安全感来源
一旦出现以上迹象：
立刻简化目标，回到现实输出

七、90 天执行锚点（每一版都必须存在）
每个 90 天周期，只允许关注三件事：
1. 一个可交付成果（项目 / 技能）
2. 一个可验证进步（考试 / 面试 / 输出）
3. 一个结构优化点（方法 / 作息 / 流程）
超出部分，视为噪声。

八、最终校验标准（长期适用）
这套体系，是否让我的现实生活：
● 更稳
● 更可控
● 更少自我消耗
如果答案是否定的：
不是你不行，是体系需要降级。
