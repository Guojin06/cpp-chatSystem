### 3. 修复 `db_handler.cpp` 编译错误

**问题类型**: 类型转换错误

**错误信息**:
```
error: invalid conversion from 'void**' to 'sqlite3**'
error: invalid conversion from 'void*' to 'sqlite3*'
```

**原因**: 头文件 `db_handler.h` 中 `db_` 成员定义为 `void*`，但在 `db_handler.cpp` 中直接作为 `sqlite3*` 使用

**修复前**:
```cpp
// db_handler.h
void* db_;  // sqlite3* 句柄，用 void* 避免暴露 sqlite3.h 依赖

// db_handler.cpp
int rc = sqlite3_open(dbPath.c_str(), &db_);  // ❌ 错误
sqlite3_close(db_);  // ❌ 错误
```

**修复后**:
```cpp
// 所有 sqlite3 API 调用都需要显式转换
int rc = sqlite3_open(dbPath.c_str(), reinterpret_cast<sqlite3**>(&db_));
sqlite3_close(reinterpret_cast<sqlite3*>(db_));
sqlite3_exec(reinterpret_cast<sqlite3*>(db_), sql, ...);
sqlite3_prepare_v2(reinterpret_cast<sqlite3*>(db_), sql, ...);
```

### 4. 修复函数签名不一致

**问题**: `queryUnuploaded()` 函数在头文件和实现文件中签名不一致

**错误信息**:
```
error: no declaration matches 'std::vector<MeterRecord> DbHandler::queryUnuploaded() const'
note: candidate is: 'std::vector<MeterRecord> DbHandler::queryUnuploaded(int) const'
```

**原因**: 头文件声明有 `int limit = 200` 参数，但实现文件没有

**修复前**:
```cpp
// 实现文件
std::vector<MeterRecord> DbHandler::queryUnuploaded() const {
```

**修复后**:
```cpp
// 实现文件
std::vector<MeterRecord> DbHandler::queryUnuploaded(int limit) const {
    char sql[256];
    snprintf(sql, sizeof(sql), 
        "SELECT * FROM meter_records WHERE uploaded = 0 ORDER BY id ASC LIMIT %d", 
        limit);
    // ...
}
```
