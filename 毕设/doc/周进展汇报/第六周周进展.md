### 2. 代码结构梳理

撰写了详细的C++语法学习笔记，包括SQLite数据库操作、MQTT协议原理等知识点。通过实际编码实践，深入理解了prepare/reset/finalize等函数的区别和使用场景。建立了系统化的知识库，为后续开发和论文撰写提供了基础。

### 4. 期中汇报材料准备

根据已完成的功能模块，整理了期中汇报所需的PPT内容和演示流程。包括项目概述、技术方案、已完成功能清单、下一步计划等部分，为下周二的期中汇报做好了充分准备。

## 下阶段工作内容

### 1. 期中汇报准备（4月15日-16日）

完成期中汇报PPT的制作和演示环境的调试。下周二的期中汇报需要展示DTU网关的数据采集、本地存储、MQTT发布等完整功能，确保各环节能够正常运行。准备答疑材料，预设老师可能问到的技术问题，如协议选择原因、数据可靠性保障机制等。

### 2. MQTT功能完善

配置并启动本地MQTT broker进行实际测试，验证消息发布和订阅功能是否正常工作。将MQTT连接参数从配置文件读取，完善错误处理和重连机制。在有网络条件时，尝试接入云平台进行实际数据传输测试。

### 3. 重传机制设计

设计并实现断网后的重传机制，采用指数退避算法避免频繁重试。研究不同QoS级别对数据可靠性的影响，根据实际需求选择合适的服务质量等级。这部分内容将是论文网络可靠性实验的核心。

### 4. 可靠性实验方案设计

参照论文初稿中的实验设计，使用Linux tc命令模拟网络故障场景，包括丢包率和延迟等因素。设计对比实验方案，量化分析有无重传机制情况下的数据完整率差异，为论文提供实验数据支撑。
